# Credit Card Financial Dashboard

Domain: Financial Analytics | Business Intelligence

### Project Overview

This project focuses on building an interactive Credit Card Financial Dashboard to monitor and analyze key performance metrics on a weekly basis. The dashboard is designed to provide a clear, real-time view of both customer behavior and transaction trends, helping stakeholders make data-driven decisions with confidence.

The solution is structured into two major analytical views:

Customer Dashboard – who the customers are

Transaction Dashboard – how customers are spending

Together, these views deliver a 360° understanding of revenue, risk, and customer segmentation.

### Project Objective

The primary objective of this project is to:

1. Track financial performance and customer behavior using credit card data

2. Identify revenue drivers, high-risk segments, and spending patterns

3. Enable week-on-week (WoW), month-on-month (MoM), and year-on-year (YoY) performance comparisons

4. Support business teams with actionable insights through intuitive visualizations

### Dashboard Structure

Customer Dashboard

This section focuses on customer demographics and segmentation, covering:

1. Customer categories and segments
2. Income groups
3. Job profiles
4. Education levels
5. Card ownership distribution
6. Customer contribution to overall revenue

It helps answer questions like:

1 Which customer segments generate the most revenue?
How does income or occupation influence spending and delinquency?
What customer profiles carry higher financial risk?

Transaction Dashboard

This section analyzes spending behavior and financial performance, including:

1. Total revenue and interest earned
2. Delinquency rates
3. Expenditure types (spending categories)
4. Card type performance
5. Transaction volume and value trends

It enables analysis of:

1. High-performing and underperforming card types
2. Changes in spending patterns over time
3. Revenue contribution by transaction category

Time-Based Analysis

The dashboard supports multi-level trend analysis through:

1. Week-on-Week (WoW) comparisons
2. Month-on-Month (MoM) growth tracking
3. Year-on-Year (YoY) performance evaluation

This allows stakeholders to quickly identify growth patterns, seasonal trends, and anomalies.

Key Metrics Tracked

1. Total Revenue
2. Interest Earned
3. Delinquency Rate
4. Customer Count
5. Transaction Volume
6. Spend by Category
7. Revenue by Card Type
8. Segment-wise Performance

### Business Value & Insights

This dashboard helps:

1. Identify profitable customer segments
2. Monitor credit risk and delinquency trends
3. Optimize card offerings and marketing strategies
4. Support leadership with data-backed financial insights

It is designed to be intuitive for both technical and non-technical stakeholders.
